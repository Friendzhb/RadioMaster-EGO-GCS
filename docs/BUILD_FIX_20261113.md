# 2026-11-13 构建修复与源码迁移

迁移基线为提交 `3902516f3be572c3980228cc88d99ea186643162` 中的
`RadioMaster_EGO_GCS_Native_Android (19).zip`。原始成员和 SHA256 见 `SOURCE_IMPORT.json`。
旧 ZIP 从当前目录移除，原始版本仍可通过 Git 历史找回；没有改写历史。

最近失败运行 `43359469120` 在 `RosTopicInspector.kt` 的 TCPROS 重试握手中失败：
`handshaked` 在赋值表达式中重设，编译器不能将复杂表达式 `handshaked.discoveredMd5`
稳定推断为非空字符串。现将 MD5 保存在局部不可变值中，判空后传给重试握手，
保留原有通配 MD5 探测及服务端真实 MD5 重连行为。

仓库现在使用可直接审阅的源码、完整 Gradle Wrapper 8.7、分发包 SHA256、统一格式检查和
Android Lint。CI 不再从一组上传 ZIP 中猜测构建来源。

原工程固定签名已转入主仓库的 Actions Secrets：

- `EGO_GCS_OTA_KEYSTORE_B64`
- `EGO_GCS_OTA_STORE_PASSWORD`
- `EGO_GCS_OTA_KEY_ALIAS`
- `EGO_GCS_OTA_KEY_PASSWORD`

沿用既有证书以兼容已安装的开发版本，CI 会核对证书的公开 SHA256。

因此这份历史证书不能被视为保密的生产证书；本次没有自动更换证书或破坏覆盖安装兼容性。
