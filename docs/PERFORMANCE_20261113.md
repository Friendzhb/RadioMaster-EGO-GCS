# 3.12.0 渲染与遥测改进

源码基线：`df724da757dc365eeb2e0676609a2c7285f949c0`。
保留现有画质档位、30万点容量、近场保留策略、主题、投影、透镜遮挡及轨迹动效。
机载控制器、飞控固件、控制参数没有修改。

## 实现

- 引擎保持50 Hz；渲染用 Choreographer 调度，现有档位分别最高60/60/30帧，最多一个待绘制请求。
  HUD 在主线程按10 Hz/省电7 Hz读取最新快照，前后台切换撤销和恢复回调，不再依靠 GL 线程 sleep 限帧。
- 发布者与各消费者持有独立快照；短临界区仅复制数据，绘制和格式化在锁外执行。
  删除缺少读者占用保护的四缓冲循环复用，数组与集群子帧均深复制。
- 点云改为4096点一页、每帧最多四页/16384点；2 ms是上传循环的软预算，不能中断单次显卡驱动调用。
  GL 用 tryLock 获取一致的分块副本，生产者忙则延后，不读取正在写入的影子数组。
  分块版本避免丢掉上传期间的新修改；清图按世代失效，EGL重建渐进恢复；仅绘制已初始化的连续范围。
- 网格和体素几何按精确输入缓存。地图、相机、投影及显示条件改变时失效，动态机体与轨迹继续更新。
  缓存命中时跳过相应 VBO 重传。帧耗时统计保留原始值，不再将超过50 ms的慢帧截短。
- 新增默认关闭的 [ROS UDP入口](ROS_UDP.md)，仅用于点云和位姿接收，指令仍走可靠链路。

## 实测与测试

本机实际运行 JDK17、Android SDK34、API28 x86_64 模拟器、OpenGL ES2 软件渲染。
渲染对照使用4096个体素、固定输入和动画时钟，在同一渲染器内切换几何缓存，覆盖四主题和2D/3D。

| CPU渲染耗时 | 缓存关闭 | 缓存开启 |
| --- | ---: | ---: |
| 中位数 | 1.89046 ms | 0.36099 ms |
| P95 | 6.35153 ms | 0.97067 ms |

原始结果见 [render-benchmark-20261113.json](render-benchmark-20261113.json)。
这是缓存模块的消融对照，不是旧APK与新APK的整机帧率测试，不能直接换算AX12上的FPS或功耗。
连续300个静态帧后的Java保留堆变化为114688字节；这是短时增长检查，不是长期泄漏证明。

本地最终验证：

- Kotlin JUnit：16项通过，包括快照并发、字段完整性、分块积压/修改/清图/重建、帧率调度、UDP组包及跨语言协议样本。
- Python：4项通过，包括真实 UDP 回环、大小端及行填充、整数反射率、采样上限和非法输入。
- Android集成：5项通过，包含 UDP→生产引擎及断流回退、四主题/双投影等逐像素一致性、实际主页启动、前后台恢复、30万点与两次GL上下文初始化。
- `spotlessCheck`、`testDebugUnitTest`、`lintDebug`、`assembleDebug` 和 `assembleDebugAndroidTest` 通过。

CI 增加 Android 9 集成测试；主分支必须通过构建和模拟器测试两个任务才更新 OTA 下载入口。
包名和既有 OTA 签名保持兼容，上一版 APK 保留在本地归档。
