# 科研级三维无人机渲染架构（4M2S 双舵倾转 & X4 常规四旋翼）

主三维点云地图（含单机与 2–4 机异构编队）及右下角实时姿态视窗统一由 OpenGL ES 2.0 硬件实体渲染器 `VectorGlbRenderer` 驱动：

1. **外部高精度 GLB 优先加载（可选）**
   若 `app/src/main/assets/vector_uav.glb` 存在（原始 SHA-256：`0ff402d8e9a7e9470e0f2c6b010955f035e5667617715c4ef02a303e6af14ab5`），加载器直接通过内存映射解析 `joint_f`（前倾转轴 M1/M3）与 `joint_b`（后倾转轴 M2/M4），提取电机几何轴心作为三叶螺旋桨同心旋转中心，并附加高可视度桨尖涂装。

2. **内置科研实机三维 CAD 网格（零外部体积开销）**
   未打包外部 GLB 或处于常规四旋翼模式时，`VectorUavMeshBuilder` 自动生成米制 URDF 比例（轴距半径 `0.18817742 m`）的高精度实体网格：
   - **科研航电核心**：双层斜纹碳纤机架板、CNC 钛合金六角铝柱、边缘计算散热鳍片、顶部 Livox Mid-360 混合固态激光雷达（含蓝宝石光学视窗与四柱防撞保护笼）、机头 Intel RealSense D435i 双目深度相机三镜头模组、机腹高倍率软包锂电 + 凯夫拉绑带 + 黄色 XT60 电源插头。
   - **4M2S 双舵矢量倾转构型（`buildProceduralTiltUav`）**：前/后双横轴倾转碳纤圆管、`joint_f` / `joint_b` 独立俯仰关节、阳极氧化金金属舵盘与推拉连杆，实时响应 `tiltServo1Rad` / `tiltServo2Rad`。
   - **X4 常规科研四旋翼构型（`buildProceduralStandardQuad`）**：刚性 45° 对角碳纤圆管机臂与 CNC 电机端座，与双舵构型共享全套机载传感器与动力细节。
   - **无刷外转子与三叶碳纤螺旋桨**：镂空散热窗外转子钟罩（内露紫铜定子绕组）、前红后绿航空航向灯珠、CNC 铝合金锥形桨帽、带根梢扭转角的窄弦三叶碳纤桨叶及高反差双色桨尖（前橙红 / 后翠绿）。

3. **解锁联动与物理启停惯性（`RotorSpinState`）**
   - 仅当飞控处于解锁状态（`armed == true`）或存在有效电机推力遥测（`max(motorNorm4) > 0.045`）时驱动螺旋桨旋转；上锁且无油门时完全静止（`0 rad/s`），零残影叠加，清晰呈现三叶碳纤桨叶与桨尖涂装。
   - 启动加速采用一阶电机转动惯量（`τ_up = 0.135 s`），上锁停桨采用气动阻尼 + 无刷齿槽退磁制动曲线（`τ_down = 0.215 s`）平滑减速至静止。
   - 视觉角速度避开 30/60 FPS 下三叶桨 `120°` 频闪驻波谐波，并叠加按转速动态渐显的三叶顺/逆时针旋向运动模糊尾迹扇、径向羽化桨盘与翼尖涡流光环。
