# 矢量无人机 GLB 模型

`app/src/main/assets/vector_uav.glb` 是从矢量无人机仿真模型导出的原始 GLB，未做减面或重建。模型 SHA-256：

```text
0ff402d8e9a7e9470e0f2c6b010955f035e5667617715c4ef02a303e6af14ab5
```

主地图与姿态小窗使用这份模型。`joint_f` 为前轴，带动 M1/M3；`joint_b` 为后轴，带动 M2/M4。两个轴沿模型各自的局部 Y 轴转动，分别使用已有快照中的 `tiltServo1Rad`、`tiltServo2Rad`。程序使用遥测或现有仿真链产生的角度，不播放 GLB 自带的示范动画；具体数据来源以应用当前连接状态为准。

GLB 加载器针对仓库内这份自包含模型实现，支持其中的无索引浮点三角网格和命名倾转节点，不是通用 glTF 编辑器。模型加载失败时，界面保留原来的示意模型并在 Android 日志中记录错误。普通四旋翼模型保持原样。

原始 GLB 约 31 MB，包含约 130 万个顶点；本次未做渲染性能优化。模拟器测试不能代表 RadioMaster AX12 实机帧率或实时遥测表现。
